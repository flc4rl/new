# Standing themes: colonialism, racism, fascism and their variations, in
# English, Italian, Spanish, French, German, Portuguese, Dutch, Danish, Swedish,
# Norwegian, Polish, Czech, Slovak, Slovenian, Croatian/Serbian, Greek, Romanian,
# Finnish, Catalan, Basque, Ukrainian/Russian, Lithuanian and Hungarian.
#
# Deliberately broader than frame_analysis/taxonomy.py: activist websites use
# the adjectives ("colonial violence", "racist borders") analytically, so
# they are included here. Remove them if you want the stricter definition.
#
# Syntax (see example_themes.txt): term* = prefix; *term* = also inside
# compound words (Technofascism, Ökofaschismus, klimaatracisme, neokolonial);
# re: = regular expression. Overlapping matches count once (the longest).
# !term = exclusion: a hit of this theme that overlaps a match of the
# exclusion is not counted ("!énfasis" keeps "*fasis*" off the Spanish word
# for "emphasis"). Greek accents are ignored when matching.
#
# A line "#: descriptive" directly under a [theme] header marks a descriptive
# theme: its hits are still recorded (theme_hits.csv, master_themes with
# focus_theme=no) and reported apart in the analytics, but they do not count for
# the theme filter or the any-theme measures. Older versions of the scripts read
# the line as a comment. To count a descriptive theme again, delete its line or
# run with --focus-themes and list it (for example
# --focus-themes colonialism,racism,fascism,global_south,authoritarianism).
