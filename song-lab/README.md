# Sudanese Arabic Song Lab

A local web app that turns songs on YouTube into study material for Sudanese (Khartoum) Arabic.

## Start

You need [Node.js](https://nodejs.org) 22.13 or newer.

```bash
npm install
```

```bash
npm start
```

The app opens at <http://localhost:5177>. Press Ctrl+C in the terminal to stop it.

Your songs, lyrics and recordings are stored in the `data` folder next to this file. That folder is ignored by git.
